# Upload checklist

- [ ] Extract `Iliya-AI-Android-Complete-Source.zip` on a computer or in a file manager that can extract ZIP archives.
- [ ] Open the extracted `iliya-ai-android` folder.
- [ ] Create a new GitHub repository named `iliya-ai-android`.
- [ ] Upload the contents of the extracted folder so `settings.gradle.kts`, `build.gradle.kts`, `app/`, `backend/`, and `.github/` appear at the repository root.
- [ ] Commit the files to the `main` branch.
- [ ] Open **Actions** and wait for **Build Iliya AI Android APK** to finish.
- [ ] Download the `iliya-ai-debug-apk` artifact from the successful run.

Do not upload Cloudflare secrets, access tokens, model API keys, signing keystores, or any private personal information.
